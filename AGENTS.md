# Repository working instructions

- Work in this repository. Keep changes general across websites and questions.
- After each logical change, run the relevant offline checks and record what was verified.
- Commit each logical change with a clear Git commit message. Keep the working tree clean when handing work back.
- Once the user has connected a GitHub remote, push committed updates to that remote when available. Report failures honestly.
- Never commit secrets, credentials, local environments, downloaded model weights, or generated reports.
- Keep the user's real-site expected-answer edits when changing agent_suite.json.
- When providing an update, explain what changed, why, how it was checked, and any live-site limitations.
